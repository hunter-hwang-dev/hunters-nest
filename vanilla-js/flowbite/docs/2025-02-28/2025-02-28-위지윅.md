이제 js 코드를 읽어 보자. 아까 저장 + 포맷팅 합치려다 실패한 이유를 찾았다:
저장 기능은 `window.addEventListener("load", function () {})` 안에서 모두 불러와지기 때문이다.

`if (document.getElementById("wysiwyg-export-example"))` 안에 있는 내용은 변수 editor에 새 Editor를 적용해 주는 코드.

```
// tip tap editor setup
const editor = new Editor({

```

1. 어느 element랑 연결된 editor인지
2. extensions 더 쓰는 거 있는지
3. content에 디폴트 문장
4. editorprops 속 attributes, class 적혀 있는 것으로 봐서 그냥 스타일인 듯. 여기에 항목 추가할 일이 생기면 더 살펴보고 패스!

```
//여전히 window "load" 이벤트 안

    const sourceCodeModal = FlowbiteInstances.getInstance(
        "Modal",
        "source-code-modal"
        );
    const sourceCodeWrapper = document.getElementById("sourceCode");
```

1. sourceCodeModal은 어디 쓰는 거지?
2. sourceCodeWrapper에 `<pre><code id="sourceCode"></code></pre>` 속의 code를 갖고 오란다. 처음 보는 태그라서 검색.
   a. `<pre>` 태그 없이 그냥 적으면 html이 태그로 인식할 수가 있음
   b. `<code>` 로 코드 스니펫 스타일 자동 적용 가능
   c. 그래서 `sourceCodeWrapper`에 뭘 추가해도 텍스트 그대로 출력됨

```
    document
      .getElementById("toggleHTMLButton")
      .addEventListener("click", () => {
        sourceCodeWrapper.innerHTML = editor
          .getHTML()
          .replace(/&/g, "&amp;") // Escape & character
          .replace(/</g, "&lt;") // Escape < character
          .replace(/>/g, "&gt;") // Escape > character
          .replace(/"/g, "&quot;") // Escape " character
          .replace(/'/g, "&#039;"); // Escape ' character
      });
```

1. `"toggleHTMLButton"`을 `"click"`하면
2. `sourceCodeWrapper.innerHTML = editor` 내용을 편집해서 넣는데
3. 아까 위에서 처음 `editor` 선언했을 때 보면 여러 항목 들어간 object라서 `.getHTML()` 씀. 왜 굳이 이렇게 우회할까 추측.
   a. const editor니까, editor.content 불러오면 죽을 쑤든 밥을 쑤든 초기 설정 값만 가져오는 건가? 그렇다고 한다!
   b. tiptap editor 자체에서 제공하는 `getHTML()` 함수! ProseMirror의 문서 구조를 HTML로 변환한단다.

아하. 실제로 flowbite는 ProseMirror를 기반으로 한 tiptap editor를 기반으로 하나 보네. 몇몇 특수문자가 변환 시에 깨질 수 있음은 알고 있는데,
정확히 뭐를 어떻게 해야 하는지는 잘 살펴보지 않았다. 이번 기회에 살펴보도록 하겠다.

#### 엔티티 변환

1. 브라우저는 여전히 HTML을 태그로 해석함
2. <pre>, <code> 로 감쌌는데도 왜 해야함? HTML5에서 자동 변환해 주는 기능이 없댄다.
3. XSS(은근슬쩍 남의 장바구니에 초코비 넣는 짓) 같은 보안 문제를 막아야 함

그렇다니 우선 받아들이자.

#### 정규 표현식 읽기 복습

`/🤓/g` = 🤓 문자를 전역으로 찾아주세요
`string.replace(/🤓/g, "☝️")` = 🤓 문자를 전역으로 찾아서 다 ☝️로 바꿔주세요

#### `JSON.stringify(editor.getJSON(), null, 2)`?

mozilla 공식 문서에서 `JSON.stringify(value, replacer, space)` 파라미터 3개 알려줬는데, 별 거 없고
space = 0 이면 보기 안좋은데 replacer 뭐라도 적어야 space 넘겨줄 수 있어서임.

#### 얘는 왜 따옴표 replace 안함?

JSON.stringify()가 자동으로 이스케이프해 줌. 출력값 보면 이렇게 적혀있잖아:
`{"type": "doc", "content": [ ... ]}`
