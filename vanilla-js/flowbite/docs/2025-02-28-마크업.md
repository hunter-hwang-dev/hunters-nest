#### `2025-02-28 금요일` 낮에는 생각보다 따뜻했고 저녁도 비슷

개발용 마크업 추가해서 헷갈리는 html 태그 구분하기

발제: @apply, @layer, 아니면 SASS SCSS로 싹 정리할 수도 있겠지만은 당장 저 태그 뭐였더라 읽기 불편.
해결: 개발용 마크업인 `data-\*` 속성 추가

그 뒤로 보기 편해서 개발하기 좋았음.

1. localStorage에 현재 작성값 저장: 무조건 json화 해야 하므로 저장은 고민할 필요 없이 쉬웠음.

```
    document.getElementById("saveButton").addEventListener("click", () => {
      this.localStorage.setItem(
        "savedData",
        JSON.stringify(editor.getJSON(), null, 2)
          .replace(/&/g, "&amp;")
          .replace(/</g, "&lt;")
          .replace(/>/g, "&gt;")
      );
    });
```

2. localStorage에서 해당 값 불러오기 - https://tiptap.dev/docs/editor/api/commands/content/set-content

   a. tiptap 공식 문서에서 `setContent`는 plain text, HTML, JSON 모두 지원한다고 함.
   b. editor.commands.setContent(여기에 바로 localStorage.getItem) 꽂아넣으면 형태 있는 텍스트가 아닌 생짜 json 텍스트 노출됨 주의.

```
    const savedData = JSON.parse(this.localStorage.getItem("savedData"));
    console.log(savedData);
    editor.commands.setContent(savedData);
```
