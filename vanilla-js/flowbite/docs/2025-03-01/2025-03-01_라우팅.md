#### `2025-03-01 토요일` 찌뿌둥한 느낌

리스트 페이지를 뻥 비워놓긴 했지만, 만들었으니깐은 이어줘야겠지?

```
//server.js
app.get("/savedlist", (req, res) => {
  res.sendFile(path.join(__dirname, "savedlist.html"));
});
```

가장 쉽게 `<a>` 태그 써보기. 버튼을 `<a href="/savedlist">` 로 감싸니 잘 작동한다.
지금은 vanilla js에서 기틀 잡고 있고, 나중에 react로 넘어가면 그에 맞는 방법으로 마이그레이션 예정.
